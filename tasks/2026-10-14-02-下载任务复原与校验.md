# 2026-10-14 任务 02：WSL 下载任务复原与完整性校验

**目标**：上个沙箱中断的下载任务是什么？下载是否完整？能否继续？

## 做了什么

1. 扫描 `F:\linux`：发现 `parts\wsl.msi.part.00-17`（分片下载现场）+ `wsl2.msi` + `enable.bat`/`dism.log`
2. 复原任务链：上个沙箱在做「启用 WSL 功能（DISM）→ 分片下载 WSL2 安装包」，中途额度耗尽
3. 完整性校验：分片 00-17 共 367,575,040 字节，拼接后 SHA256 `AE977286...F211` 与 `wsl2.msi` **完全一致**，MSI 文件头合法 → **下载已完成**
4. 静默安装 WSL 3.0.3.0 成功（MSIEXIT=0）

## 结果

- 下载任务闭环：无需重下
- WSL2 功能已由 DISM 启用，但需重启生效（`RebootPending=True`）
- WSL/Docker 位置与资源约束按用户要求配置（见任务 2026-10-15-02）

## 经验

- 远程 Windows 操作走「SFTP 传 .ps1 + `powershell -File`」最稳（stdin 管道会静默失败）
- Windows OpenSSH 默认 shell 是 cmd.exe，中文输出是 GBK，需 `iconv -f GBK` 或脚本内 `[Console]::OutputEncoding=UTF8`
