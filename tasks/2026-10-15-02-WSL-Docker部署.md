# 2026-10-15 任务 02：WSL/Docker 沙箱环境部署（E:\linux）

**目标**：按用户要求把 WSL + Docker 装到 `E:\linux`，内存限 1G，开机不自启。

## 用户约束

- WSL 子系统必须装在 `E:\linux`，Docker 同样
- WSL 内存上限 1G（Docker 共享该上限）
- 除非手动启动，否则开机默认不启动（防止后台偷跑资源）

## 做了什么

1. 重启前：创建 `E:\linux`、写 `C:\Users\43551\.wslconfig`（`memory=1GB`/`swap=2GB`/`processors=4`）、`wslservice` 改为 Manual（开机不自启）
2. 用户重启后验证：WSL 3.0.3.0 就绪、默认版本 2、暂无发行版
3. 执行 `E:\linux\wsl-docker-setup.ps1`（后台）：
   - `wsl --update` → `wsl --install -d Ubuntu --no-launch` → `wsl --manage Ubuntu --move E:\linux`
   - Docker Desktop 安装到 `E:\linux\Docker`，数据盘 `E:\linux\DockerData`
   - 关闭 Docker 自启（settings.json `autoStart:false` + Run 键清理 + com.docker.service 手动）

## 结果

- WSL2 重启后正常（此前 systeminfo 的 "hypervisor detected" 是 Win11 VBS 所致，物理机不受影响）
- 安装脚本后台执行中，日志：`E:\linux\setup.log` / `setup.err`
