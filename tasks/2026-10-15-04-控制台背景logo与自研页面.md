# 2026-10-15 任务 04：控制台背景+logo 全站化 + 自研实时流量/系统监控页

**目标**：机主反馈"背景图/logo 没显示"（此前只加在首次向导页）；要求背景图作为**整个网站**的背景；实时流量、系统监控换成自研页（不要原版）；顺带修控制台报错。

## 结论（先说根因）

- 控制台（`/www/luci-static/yueyue/` React SPA）此前用的是**旧版** bg/logo 资源，且暗色遮罩 0.70→0.86 太浓、浅色主题 0.90→0.95 几乎全遮 → 背景"看不见"；新图只进了向导页 → "logo 没显示"。
- 控制台 404 三项（无线 `network/wireless`、软件包 `admin/package-manager`、多拨 `services/mwan3`）：固件是 luci-light 组合，这三个是新版 JS 视图应用，Lua 调度器下无对应页面 → 404。其余原版页（含状态/日志/进程/DHCP/防火墙等）实测均 200。

## 做了什么

1. **全站背景 + logo**：替换 SPA 资源 `bg-BbiUDa6X.webp`（新背景图，真 webp 117KB）+ `logo-DE7xEWH4.png`（白发少女贴纸 320px）；遮罩调淡（暗色 .38→.78 / 浅色 .60→.88）让插画背景透出来。
2. **自研实时流量页** `pages/traffic.html`：当前↓/↑速率、累计流量、2 分钟吞吐趋势图、接口明细表（在线状态/速率/累计），2s 采样，API 不可用自动降级演示数据。
3. **自研系统监控页** `pages/monitor.html`：CPU/内存/负载/运行时间卡片 + CPU/内存历史曲线 + 存储/交换 + 网络接口表，2s 采样。
4. **数据 API**：`yueyueconsole.lua` 新增只读 `admin/yueroute/api/sysinfo`（/proc/stat、meminfo、loadavg、uptime、net/dev、ubus 接口、df）。
5. **菜单改指**（SPA bundle 字符串补丁）：`仪表盘`→`系统监控`（自研 monitor.html）、`实时流量`→自研 traffic.html；原版对应页不再引用。
6. **自动排列布局优化**（路由可视化·工作流式编辑）：原算法三列硬排（y=40+i×118、云端固定 160）→ 改为整体垂直居中 + 目标节点按连接接口重心排序（减少连线交叉）+ 云端节点对齐中线。
7. 全部灌入 QEMU 虚拟机实测（静态 200、API 返回 JSON、菜单补丁生效），Edge 无头截图 ×3 + 多模态复核（背景/logo/图表/表格均正常无破版）。

## 结果

- 控制台全站背景插画可见、白发少女 logo 在侧栏和自研页均显示
- 实时流量 / 系统监控 = 自研玻璃拟态页，菜单直达
