# 2026-10-15 任务 05：背景图全站生效（原版 LuCI 页面接入插画背景+玻璃拟态）

**目标**：机主要求"背景图在所有页面都生效"。此前向导页、SPA 控制台、自研流量/监控页已有插画背景，但菜单里跳转的原版 LuCI 页面（状态/日志/防火墙/系统管理等）是纯白主题底，观感割裂。

## 结论（先说根因）

- 控制台 SPA 把原版 LuCI 页面以 **iframe** 嵌入，这些页面走 **luci-theme-bootstrap**（25.12.5 快照 26.284 版 `cascade.css`），`body` 是纯色浅底 → 背景"没生效"。
- 向导页自带 `/yueyuewizard/bg.jpg`、SPA/自研页用 `assets/bg-BbiUDa6X.webp`（同一插画，仅亮度微差），均已正常。
- 登录页 + 所有 Lua 调度器页面渲染同一套主题模板 → **只在主题层做一次全局背景+玻璃拟态，即可覆盖全部页面**。

## 做了什么

1. **全局样式** `files/www/luci-static/yueyue/yueyue-bg.css`：
   - 插画背景 + 渐变遮罩（浅色 `rgba(238,244,242,.60→.88)` / 深色 `rgba(15,26,25,.42→.82)`，与 SPA 遮罩参数一致）
   - 玻璃拟态：顶栏深色玻璃（blur 16px），内容卡片/表格/操作条/面包屑/登录弹窗浅色玻璃（blur 14-18px），暗色模式（`[data-darkmode]`）同步适配
2. **注入器** `files/etc/uci-defaults/99-yueyue-bg`（幂等、带 `yueyue-bg v1` 标记）：把上述 CSS 追加到 `bootstrap` / `bootstrap-light` / `bootstrap-dark` 三个主题的 `cascade.css`；固件首启自动执行，已部署设备可手动执行同一脚本
3. **共享背景** `files/www/luci-static/yueyue/assets/bg.jpg`（与向导 bg.jpg 同源）
4. **灌入 QEMU 虚拟机实测**：CSS 追加成功（标记校验通过）、bg.jpg 200；确认 `mobile.css` 不覆盖 `body` 背景，小屏不受影响
5. **Edge 无头截图 ×9 + 多模态复核**：控制台 / 实时流量 / 系统监控 / 登录页 / 状态总览 / 系统日志 / 防火墙 / 系统管理 / 向导 —— 9 页全部显示插画背景 + 玻璃卡片、文字可读、无破版
