## 避坑

- **Windows 侧 node_modules 平台不对**：`ui\node_modules` 里只有 `@rollup/rollup-linux-x64-gnu` / `@esbuild/linux-x64`，且 `.bin` shim 丢失 → Windows 上 `npm run build` 报 `tsc 不是内部或外部命令`、`Cannot find module '@rollup/rollup-win32-x64-msvc'`。修复：在 Windows 重跑 `npm install`，或像本次一样在 Linux 侧构建后回传产物
- 截图管线复用上一轮工具：`yshot.bat <route> <name>`（无头 Edge，输出 `F:\linux\work\yy-<name>.png`）+ `/yshot.html?route=/xxx` 自动登录跳 SPA；本次给 yshot.html 加了 `route=login` 分支截登录页
- PowerShell 带 `$` 的内联命令经 ssh+cmd 会被变量展开吃掉（`$_.FullName` 变空）→ 一律写 .ps1/.bat 传过去执行
