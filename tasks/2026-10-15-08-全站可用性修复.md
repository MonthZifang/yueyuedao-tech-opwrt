# 2026-10-15 任务 08：全站可用性修复（按钮失灵/502/401/404）+ GitHub 同步

**目标**（机主反馈）：控制台报 `404`、`personalization 401`、`diag 502`，**很多地方点了无效**；修复后同步推送 GitHub。

## 根因与修复

### 1. 「点了无效」—— rpcd ACL 缺失（主凶）
- 实测 root 会话调用 `network.wireless status` / `network.interface.X up|down|renew` / `network reload` 全部 `-32002 Access denied`
- 根因：固件 `/usr/share/rpcd/acl.d/` 里的 LuCI ACL（luci-base/luci-mod-network）**没有给 `network.*` 这些 ubus 对象授权**（LuCI 自己走 `luci-rpc` + `file exec ifup/ifdown`，不碰这些对象）→ 自研 React 页面全部哑火：无线页空白、接口页按钮无反应、DHCP/防火墙保存到一半失败
- **修复**：新增 `files/usr/share/rpcd/acl.d/yueyue-console.json`，按 `hostapd.*` 通配符先例补齐 `network.*` / `network.interface.*` / `iwinfo` / `service` / `session` / `system` 与 uci 配置读写授权
- 复测：`network reload` [0]、`network.interface dump` [0]、`iwinfo devices` [0]、uci 全通 ✅

### 2. `diag 502 Bad Gateway`—— traceroute 超时
- `traceroute -n -m 15 -w 2` 最坏 ~90s，uhttpd 杀掉超时 CGI 返回 502
- **修复**：`-m 12 -w 1 -q 1`（最坏 ~12s）+ `head -c 8192` 截断输出；空输出给占位提示

### 3. `personalization 401`—— 未登录拉展示配置被拒
- **修复**：CGI 分发里 `personalization` 的 GET 公开（纯展示用途），POST/写入仍 `need_root()`

### 4. `404`—— 浏览器找 /favicon.ico
- **修复**：SPA 与根跳转页均加 `<link rel="icon" href="assets/logo.png">`

### 5. 无线页容错（附带）
- `network.wireless status` 在部分 netifd 必须显式 `device` 参数（VM 无无线返回码怪异）→ 加回退链：全量 status → `iwinfo devices` 逐设备查 → 空态友好提示（不再弹报错 toast）
