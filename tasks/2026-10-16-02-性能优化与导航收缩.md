# 2026-10-16 任务 10：性能优化 + 失效功能修复 + 导航分类收缩

**目标**（机主指示）：优化页面性能、修复部分功能点击后无法正常启用调用、菜单进行分类和收缩。

## 排查方法（先拿证据再动手）

1. **API 全量冒烟**（smoke_all.sh / smoke_write.sh）：CGI 全部 action + ubus 全对象，curl 实测；
2. **真浏览器点击审计**（uitest.js，puppeteer-core 驱动 Edge）：登录后走 19 个路由、点按钮、抓 console 报错/失败请求/toast；
3. **会话级 ubus 探测**（probe.js）：浏览器会话内逐对象调用，区分 ACL 拒绝与方法缺失。

**定位到的失效根因**：
- `/dhcp` 页报 Access denied：ACL（`acl.d/yueyue-console.json`）漏了 dnsmasq 的 `dhcp` ubus 对象；
- ACL 补上后变 code 3（method not found）：**本固件 dnsmasq 只注册 `ipv6leases/ipv6ra/add_lease`，没有 `leases` 方法**——前端调用的 API 本身就不存在；
- 连锁影响：租约加载失败会拖垮整页（同一 try 块），DNS 保存、静态租约全部不可用。

## 修复

1. **CGI 新增 `dhcp_leases`**：直接读 `/tmp/dhcp.leases`（解析到期时间戳/MAC/IP/主机名，转剩余秒数），不依赖 dnsmasq ubus API；
2. **前端 DhcpDns**：改走 `api.dhcpLeases()`；租约与 DNS 配置拆成两段独立容错，一段失败不拖垮另一段；
3. **ACL 补齐**：`dhcp`（read: leases / write: add_lease, delete_lease）+ `mwan3.status` 显式声明；
4. Mwan3 页过时文案修正（原提示安装 luci-app-mwan3，LuCI 已移除）。

## 性能优化

1. **路由级代码分割**（React.lazy + Suspense）：入口 JS 88.5KB → **24.6KB**，19 个页面全部按需加载（各自 2.7–8.8KB chunk），首屏下载量大幅下降；
2. **后台标签页暂停轮询**：useInterval 在 `document.hidden` 时跳过 tick，回前台立即补一拍（实时流量 2s/进程 5s/日志 5s 轮询不再空转）；
3. 去掉 `.yy-bg` 的 `background-attachment: fixed`（与 position:fixed 重复，低端设备上是渲染负担）。
