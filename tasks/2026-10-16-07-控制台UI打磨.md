# 2026-10-16-07 控制台 UI 打磨（导航/表情清理/图表修复/路由工作流优化）

> 任务 15（机主指令：侧栏默认开 + 分组默认折叠 + 删按钮 emoji + 修性能图"弯曲" + 路由工作流优化 + 加连接数）

## 目标

按机主 6 条要求打磨 React 控制台 UI。

## 改动明细

1. **左侧导航栏默认展开**：`Layout.tsx` 初始 `collapsed=false`（原默认关闭）。
2. **菜单分组默认全部折叠**：`流量与监控 / 网络 / 服务 / 系统 / 月月岛` 默认收起（▸），只有用户点击才展开并持久化；移除旧的"进入页面自动展开所属分组"逻辑；搜索时自动展开匹配项；**首页无分组标题，始终可见**（实测中发现首页被误折叠的 bug，已修复：无 label 分组不参与折叠）。
3. **全站表情符号清理**：菜单图标、按钮、卡片、节点图标、右键菜单、设置抽屉里的 emoji（🪄🎯💾⚡📡🌍🧠 等 60+ 处）全部移除，保留 ▾▸☰✓✕↑↓→← 等单色功能性字符；密码可见性按钮改文字「显示/隐藏」；主题切换改文字「深色/浅色」。
4. **性能图表"弯曲"修复**（根因：`LineChart` 用 `viewBox 640×H` + `preserveAspectRatio="none"` 非等比拉伸，线条/文字/刻度全部变形）：
   - `LineChart` 改为 **ResizeObserver 实测容器宽度 1:1 渲染**，`strokeLinejoin="miter"` 尖角折线，文字刻度不再拉伸；
   - `RealtimeTraffic` 迷你走势图改 `preserveAspectRatio="none"` + `vector-effect="non-scaling-stroke"`，铺满宽度且线宽恒定。
5. **路由工作流优化**：
   - 移除画布右下角操作提示浮层（wf-hint）；
   - **运行时路由表默认不显示**（纯展示信息，设置抽屉开关保留可随时打开）；
   - 节点/工具栏/右键菜单去表情后视觉统一；
   - **新增「连接数」指标**（摘要 pill 行：接口/静态路由/运行时路由/**连接数**，数据来自 `api.sysinfo().conn`）。
