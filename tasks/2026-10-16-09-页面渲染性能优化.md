## 改动清单（ui/src）

### 1. 路由工作流画布（RouteViz.tsx，v3 → v3.1）— 本次主要收益
- **mousemove 按帧合并（rAF）**：拖拽节点 / 平移画布 / 拖动连线改绑的 mousemove 触发频率远高于刷新率，原实现每个事件 setState 一次（100 模拟设备时每帧重渲染 200+ DOM 节点）。现改为只记录目标值、每个动画帧最多提交一次状态更新，手势结束（mouseup）时冲刷残留，不丢最后一步位移。
- **节点视图 memo 化**：抽出 `CoreNode / IfaceNode / RouteNode / SimNode` 四个 `React.memo` 组件；`startDrag / openCtx / openEdit / edgeDownStart / edgeClick` 全部 `useCallback` 稳定引用（`startDrag` 内部走 `posOfRef`，否则拖拽时 handler 变化会导致所有 memo 节点跟着重渲染）。拖拽时只有被拖节点重渲染。
- **连线层 memo 化**：`EdgeLayer` 独立 memo 组件，平移 / 缩放时整个 SVG 连线层跳过重渲染。
- **拓扑数组缓存**：`ifaces / nodes / routes / staticRoutes / runtimeRoutes` 全部 `useMemo`（原先每帧 `.filter()` 重建数组导致连线 memo 恒失效）。
- **连线查找 Map 化**：`nodes.find` O(n²) → `Map.get`（100 模拟设备时每帧 100 次查找 → O(1)）。
- **`.wf-world` 加 `will-change: transform`**：拖拽 / 平移 / 缩放只走合成，不整层重绘。
- **模拟设备连线不再跑流动动画**：100 条 sim 连线原本全部挂 `wf-flow` 无限 dash 动画（持续重绘 SVG），现仅真实连线保留（设置抽屉「连线流动动画」开关语义不变）。

### 2. 画布交互 bug 修复（本次回归测试暴露，真 bug）
- **可见连线吞点击（edge_select 时灵时不灵的根因）**：`.wf-edge` 是 2px 虚线 + 流动动画，点击落点恰好压在实线段时命中的是没有事件处理器的可见路径，事件冒泡到画布弹错框；落在虚线空隙才透到下层 16px 命中层。纯看动画相位。修法：`.wf-edge { pointer-events: none }`，点击统一透到命中层，命中稳定。
- **`fitView` 闭包过期**：「模拟 100 设备」后 80ms 的自动适应视野读的是生成前的布局快照（setTimeout 闭包里的 state 是旧值），100 个模拟设备根本没进视野。修法：`fitView` 改走 `layoutRef / autoPosRef` 读最新布局。
- **拖拽后误弹快捷框**：`movedRef` 原先拿 `panStart`（只有平移才写）判断是否移动过，节点拖拽后松手可能误判为点击。修法：统一 `downAt` ref 记录按下点。
