## 需求（机主原话要点）

1. 工作流页面**右边添加属性面板**：鼠标选中某个网络或线路时，查看它连接对应的网络信息（上游 / 下游）；选中目标是设备或网络目标设备时，直接显示当前设备的 IP、子网掩码、上传流量、下载流量、租期时间等。
2. **初始化页面添加「是否为主路由」**。

## 改动清单

### 1. 路由工作流右侧属性面板（`ui/src/pages/RouteViz.tsx` + `theme.css`）

- 画布右侧新增常驻属性卡 `wf-props`（320px，sticky，窄屏 <1100px 自动落到下方）；`sel` 选中即联动（节点 / 设备 / 连线均可）。
- **接口节点（wan/lan）**：基本信息（名称/网络设备/协议/在线时长）、网络信息（IP / 子网掩码 / 网关 / 角色）、流量（累计收发 + 当前速率，sysinfo 差分）、上游（wan→上级网络+核心；lan→核心+各上联口）、下游（wan→经此口的静态路由；lan→接入设备列表）。
- **设备节点（模拟设备 / 接入设备）**：IP、子网掩码、MAC、主机名、DHCP 租期剩余、本月上传/下载/合计流量（traffic 按 IP 匹配），上游链路（接入接口→核心→上联口），下游注明终端设备。
- **路由节点**：目标网段/网关/出口/跃点/路由表/来源，上游=核心，下游=出口接口详情 + 其下设备；面板内直出 编辑/停用/删除 操作。
- **连线**：类型（设备接入/接口/路由连线）、状态，上游端点与下游端点各带详情；路由连线附编辑/停用/删除。
- **核心节点**：主机名/管理地址/运行时间/连接数/版本，上游=各 wan 口，下游=各 lan 口 + 接入台数。
- 未选中时显示操作提示 + 拓扑概览（接口/静态路由/模拟设备/DHCP 租约/连接数）。
- 下游设备列表（DHCP 租约同子网过滤 + 模拟设备）每行直接带 IP、MAC、租期剩余、本月上下行流量。
- 数据源：`topology`（接口/掩码）、`sysinfo` 10s 轮询（速率差分）、`dhcp_leases` 与 `traffic` 60s 轮询。

### 2. 后端（`files/www/cgi-bin/yueyue`）

- `wizard_mode` 新增 `main_router` 参数：`1` = 主路由（LAN DHCP 服务开启）；`0` = 二级路由（`dhcp.lan.ignore=1` 关闭本机 DHCP，由上级下发地址）；写 `yueyue.wizard.main_router` 并 commit + reload。
- `wizard_status` 返回 `main_router`。
- `iface_list` 补 `uptime`、`gateway`（默认路由 nexthop），供属性面板显示。

### 3. 初始化向导（`ui/src/pages/Wizard.tsx` + `api.ts`）

- 上联步骤顶部新增「是否为主路由」双卡选择：是（主路由，NAT/DHCP）/ 否（二级路由，关闭本机 DHCP，管理地址不变），默认是。
- 选择随 `wizard_mode` 一起提交；配置摘要页新增「网络角色」行；向导首屏文案同步。

2. ssh 控制台传中文输出用 iconv 转码会截断，改为在 Windows 侧落 `.out` 文件再经 WSL 读取（UTF-8 干净）。
