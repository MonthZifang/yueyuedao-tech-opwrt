## 做了什么

### 后端 CGI（files/www/cgi-bin/yueyue）
- **wizard_mode**：
  - `vlan` 模式网段数 2→6；每网段可传 `name/octet/ssid/key/hidden/guest/guest_ssid/guest_key/dhcp_start/dhcp_limit`
  - 新增 `allow_lan`（网段互访开关）：关=完全隔离（默认），开=网段间成对建立 firewall forwarding（`firewall_sync_interlan` 幂等重建）
  - 新增 `drop_guest_net()`：关闭访客时连带清 dhcp 池 / firewall zone / forwarding（原实现只删接口）
  - `cleanup_wizard_nets` 连带清理被删网段的 forwarding（原来会残留）
  - 落 `yueyue.wizard.nets_json` 回读快照
- **wizard_wifi** 重写：
  - 新增 `aps` 数组（逐 AP 精细配置）：`name/radio/enabled/net/follow/ssid/key/hidden/isolate/channel/width/power/guest{enabled,ssid,key}`
    - `follow=1` 跟随上级（vlan=绑定网段设置，其余=统一设置）；`follow=0` 用该 AP 独立 SSID/密码/隐藏
    - 射频参数写 radio：channel / htmode(20/40/80/160→HT20/HT40/VHT80/VHT160) / txpower
    - 客户端隔离 isolate；逐 AP 访客开关 → `yueyue_guest_<i>`（isolate=1，走 lan_guest 192.168.30.0/24）
  - 兼容旧载荷（无 aps 按 radio 轮询）；落 `yueyue.wizard.wifi_json` 回读快照
- **wizard_status** 回读：`mode / allow_lan / nets / aps / main / guest`（aps 归一化 "0"/"1"→boolean）

### 前端（ui/src/pages/Wizard.tsx 重写 + api.ts 类型）
- 组网方式步骤：AP 全部同网 / AP IP 分离 / 标准路由 / Mesh 四卡；IP 分离细化 = 网段 2-6 个增删按钮（修复旧版滑块 max=4 数组越界 bug）、逐网段名称/网段/DHCP 起始/数量/访客开关、"允许网段之间互访"总开关
- WiFi 设置步骤（按模式自适应）：
  - 统一设置卡（主 SSID/密码/隐藏 + 访客 SSID/密码）
  - **逐 AP 卡片**：名称标签 / 启用 / 删除 / 添加 AP（≤8）/ 绑定网段（vlan 模式）/ 信道（2.4G 1-13 + 5G）/ 频宽 20-160 / 发射功率高/中/低 / 客户端隔离 / 跟随上级或独立 SSID+密码+隐藏 / 逐 AP 访客开关+访客 SSID/密码
  - IP 分离：逐网段卡（SSID/密码/隐藏/访客 SSID/密码/DHCP 范围）+ 逐 AP 绑定网段
- 管理密码步骤加强度提示；摘要分组展示网段/逐 AP/访客/互访策略
- 全站去 emoji；关键控件加 `data-testid`（cc-* / wz-* / net-* / ap-*）
- 回读预填：wizard_status 的 nets/aps/main/guest 回填向导（重进不丢配置）
